# Good Night Hotel — Aurelion design adaptation

Source: https://aurelion-hotel.framer.website/

This folder contains a Good Night Hotel content adaptation of the Aurelion site's publicly accessible output, while preserving the downloaded visual structure, animations, and Framer runtime:

- `index.html` — the customized homepage
- `pages/` — the customized public HTML pages
- `assets/` — downloaded Framer-hosted images, SVGs, and fonts
- `source-manifest.txt` — all discovered public asset URLs

Hotel data used: Good Night Hotel, 45 Rue Jean Baptiste Colbert, 62510 Arques, France; `+33 3 21 93 81 20`; `sales@good-night-hotel.com`.

The files are published browser output rather than the private editable Framer canvas/project source. Framer hydration and external Framer/font requests have been removed; the customized copy is intended to run from the local Python server without a Framer connection.

The snapshot was fetched without stopping or modifying any existing local server or process.
