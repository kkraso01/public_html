# Good Night Hôtel — Haven design adaptation

This folder preserves the original Haven single-page design and interaction system while adapting the content for Good Night Hôtel in Arques.

- French is the default language.
- Use the `EN` / `FR` control in the header to switch languages.
- The original Haven CSS, Bootstrap layout, mobile navigation, booking widget, gallery lightbox, and review carousel remain in place.
- Hotel imagery is stored locally under `hotel-assets/`.

Run locally with:

```powershell
python -m http.server 8083
```

Then open `http://localhost:8083/`.
